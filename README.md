# Emoji Guess Quiz 🎯

A fun, interactive browser quiz game where players guess the word or phrase represented by emojis. Built with HTML, CSS, and JavaScript.

---

## 🧩 Project Structure

Emoji-Guess-Quiz/
├── index.html
├── style.css
├── script.js
└── README.md

- **index.html** — main HTML file with the quiz interface  
- **style.css** — styling for layout, colors, and responsiveness  
- **script.js** — game logic: loading questions, handling user input, managing scoring, feedback, etc.
